# Aexa Phase 3 ML service

FastAPI inference service for time-aware anomaly detection, five-minute degradation prediction, LIME explanations, and evidence-ranked root-cause candidates. It loads the model artifacts created by the reproducible training script; missing artifacts make inference return HTTP 503 rather than fabricate predictions.

## Local Windows commands

```powershell
cd D:\Final_year_project\ml-service
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
python scripts\prepare_dataset.py
python scripts\train_models.py
pytest
uvicorn app.main:app --host 127.0.0.1 --port 8090
```

`artifacts\prepared_telemetry.csv`, `evaluation.json`, and `model_metadata.json` are generated by the scripts; model `.joblib` files are local build artifacts. Docker builds and evaluates the models deterministically during image construction.

The CSV is deterministic synthetic demo telemetry with seeded normal segments, labeled failures, missing values, and omitted timestamps. The report uses an earliest-70%/latest-30% chronological holdout. These results are a reproducible pipeline check, not evidence of production accuracy.

## API

- `GET /health` reports model availability; returns HTTP 503 when models have not been trained.
- `GET /model/metadata` returns artifact metadata and actual saved evaluation metrics.
- `POST /api/v1/anomalies/detect`
- `POST /api/v1/forecasts/degradation`
- `POST /api/v1/root-causes/rank`

Requests use strict snake_case JSON, timezone-aware ISO timestamps, finite numeric features, and bounded arrays. See `docs/api-contracts.md` for full payloads and Spring routes.
